> **Особистий термінал кібербезпеки з ШІ-аналітиком.**
> Перевіряє *твої* пристрої, акаунти, код і гаманці — а Claude пояснює знахідки людською мовою.

Мінімалістична консоль: одна стрічка й шельний рядок вводу `phantom-[~/тека] $` унизу.
Кольори беруться з **палітри твого терміналу** (світла, темна, Solarized — підхоплюється само).

## Інструменти

Межа одна: **лише захист і лише власні ресурси.** Жодного сканування чужих систем чи збору даних про людей.

### 🖥️ Комп'ютер і сервери
| Команда | Що робить |
|---|---|
| `/audit` | Фаєрвол, шифрування диска, оновлення ОС, порти, відкриті в мережу, налаштування SSH-сервера, автологін, SIP/Gatekeeper (macOS). Оцінка 0–100 і готові команди для виправлення. Linux · macOS · Windows. Нічого не змінює. |
| `/ssh [тека]` | `~/.ssh`: слабкі ключі (DSA, RSA < 2048), ключі без пароля, права доступу, `authorized_keys`, ризиковані `StrictHostKeyChecking no` / `ForwardAgent yes`. |
| `/logs [файл]` | `auth.log` / `secure` / `journalctl`: підбір паролів по IP, **успішний вхід після серії невдалих**, входи під root, невдалі sudo. |

### 👨‍💻 Код
| Команда | Що робить |
|---|---|
| `/secrets [тека]` | Ключі AWS/GitHub/GitLab/Slack/Stripe/Google/Anthropic/OpenAI/Telegram, приватні ключі, JWT, паролі й рядки підключення в коді — **і в історії git**, а також закомічені `.env`. Значення завжди замасковані. |
| `/deps [тека]` | Вразливості в залежностях через OSV.dev: `requirements*.txt`, `poetry.lock`, `uv.lock`, `Pipfile.lock`, `package-lock.json`, `yarn.lock`, `go.mod`, `Cargo.lock`, `Gemfile.lock`, `composer.lock`. Підказує, до якої версії оновитись. |
| `/cve <id>` | CVE з NVD (CVSS, тип слабкості, вразливі продукти) + чи її **вже атакують** (каталог CISA KEV). Підтримує й GHSA. |
| `/brief [днів]` · `/stack` | Дайджест свіжих активно експлуатованих вразливостей, відфільтрованих за твоїм софтом (`/stack windows, chrome, nginx`). |

### 🎣 Фішинг і файли
| Команда | Що робить |
|---|---|
| `/phish <текст\|посилання\|лист.eml>` | Домени-двійники (`paypa1`, `monobamk`), підміна літер (кирилиця в домені, punycode), IP замість домену, `@` у посиланні, скорочувачі, ризикові зони, тиск і терміновість, **прохання ввести сід-фразу**. Для `.eml` — SPF/DKIM/DMARC, Reply-To, підробка імені відправника. Посилання не відкриваються. |
| `/file <шлях> [sha256]` | SHA-256/SHA-1/MD5 і звірка з контрольною сумою, подвійні розширення (`invoice.pdf.exe`), програма під виглядом документа, макроси в Office, виконувані файли в архівах, пошук у базі шкідливого ПЗ MalwareBazaar. |

### 🔑 Паролі й акаунти
| Команда | Що робить |
|---|---|
| `/pwned` | Чи є пароль у витоках (Pwned Passwords, k-анонімність: у мережу йдуть лише 5 символів хешу) + оцінка стійкості й часу на злам. Пароль ніде не показується й не зберігається. |
| `/passgen [довжина]` | Випадковий пароль і вимовна парольна фраза з точною оцінкою ентропії. |
| `/breach <твоя пошта>` | Витоки за Have I Been Pwned — лише після підтвердження, що пошта твоя; локально зберігається тільки хеш адреси. |
| `/incident [що сталося]` | Покроковий план: пошта, Telegram, крипта, витік пароля, вірус, підміна SIM, банк, витік ключа API, соцмережі. Працює офлайн. |

### ₿ Крипта
| Команда | Що робить |
|---|---|
| `/checkaddr <0x…> [очікувана]` | Контрольна сума EIP-55, список шахрайських адрес ScamSniffer, виявлення **«отруєння адреси»** (той самий початок і кінець, інша середина). |
| `/approvals <0x…> [мережа]` | Активні дозволи ERC-20 твого гаманця (Ethereum, Base, Arbitrum, Optimism, Polygon, BSC): необмежені дозволи невідомим контрактам, отримувачі зі списку шахраїв, поточний allowance. Сід-фраза ніколи не потрібна. |

### 🔒 Приватність
| Команда | Що робить |
|---|---|
| `/encrypt <текст\|файл>` · `/decrypt` | Шифрування паролем у форматі [age](https://age-encryption.org) — сумісно з утилітою `age`. Зашифрований текст одразу копіюється в буфер; надсилай будь-яким месенджером. |
| `/exif <фото> [--show]` | GPS-координати, модель телефона, серійний номер, дати — показати й зберегти чисту копію (JPEG, PNG). Пікселі не змінюються, оригінал не чіпається. |

### 🧠 ШІ-аналітик
| Команда | Що робить |
|---|---|
| `/explain [питання]` | Передає останній звіт Claude: що справді серйозно, що ні, і як виправити по кроках. Можна продовжувати розмову («а як це на macOS?»). |
| *просто текст* | Розмова з асистентом про безпеку чи будь-що інше. |

### Також є
Ко-пілот листування (`/polish`, `/warmer`, `/formal`, `/shorter`, `/translate`, `/reply`) і особиста
CRM з ручним введенням (`/add`, `/people`, `/show`, `/note`, `/met`, `/date`, `/remind`) — повний список у `/help`.

## Встановлення

Потрібен Python 3.11+.

```bash
git clone https://github.com/phantomtantrum/PhantomStalkerx100.git
cd PhantomStalkerx100
python -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -e ".[dev]"
quantphantom
```

Або однією командою через [pipx](https://pipx.pypa.io):

```bash
pipx install git+https://github.com/phantomtantrum/PhantomStalkerx100.git
```

Деякі перевірки (`/audit` для фаєрвола й шифрування, `/logs` для системних журналів) бачать більше, якщо
запустити `sudo quantphantom`.

## Ключі API

Більшість інструментів працює **без жодних ключів**. Ключі зберігаються лише в системному keyring
(або в змінних середовища / `.env`), вводяться приховано й ніде не показуються. Стан: `/keys`.

| Сервіс | Для чого | Як додати | Де взяти |
|---|---|---|---|
| Anthropic | розмова, `/explain`, ко-пілот | `/key` | platform.claude.com |
| Have I Been Pwned | `/breach` (платний) | `/key hibp` | haveibeenpwned.com/API/Key |
| Etherscan | `/approvals` (безкоштовний) | `/key etherscan` | etherscan.io/apis |
| abuse.ch | `/file` → MalwareBazaar (безкоштовний) | `/key abusech` | auth.abuse.ch |

Без ключів: `/audit`, `/ssh`, `/logs`, `/secrets`, `/deps`, `/cve`, `/brief`, `/phish`, `/file` (локальні
перевірки), `/pwned`, `/passgen`, `/incident`, `/checkaddr`, `/encrypt`, `/decrypt`, `/exif`.

## Клавіші

У рядку вводу видно поточну теку — з нею за замовчуванням працюють `/secrets`, `/deps` і `/file`;
змінити: `/cd <тека>`. Під час введення пароля рядок стає `phantom-[пароль] $`, під час підтвердження — `phantom-[y/n] $`.

`Tab` — доповнити команду · `↑`/`↓` — історія або вибір підказки · `Esc` — перервати / скасувати ·
`Ctrl+C` — очистити рядок, на порожньому — вихід. Багаторядковий текст (лист, зашифрований блок) можна
вставляти — переноси зберігаються (видно як `⏎`).

## Приватність

- Усе працює локально; база — `~/.phantomstalker/phantom.db`, кеш публічних даних — `~/.phantomstalker/cache`.
- Назовні йде тільки те, що потрібно конкретній перевірці: назви й версії пакетів (OSV), 5 символів хешу
  пароля (Pwned Passwords), ідентифікатор CVE, публічна адреса гаманця, твоя пошта після підтвердження.
- Знайдені секрети маскуються, паролі й сід-фрази ніколи не відображаються й не потрапляють у звіти для ШІ.
- Асистент допомагає лише захищати власні системи й відмовляє в атаках на чужі.

## Архітектура

```
src/phantomstalker/
├── app.py                  # консоль: ввід, історія, фонові перевірки, стрімінг
├── core/
│   ├── commands.py         # slash-команди, @згадки, маскування ключів
│   ├── security_commands.py# безпекові команди → фонові задачі
│   ├── persona.py · theme.py · wordmark.py
├── security/               # по модулю на інструмент, кожен повертає Report
│   ├── audit.py  sshaudit.py  logs.py  secrets_scan.py  deps.py  cve.py
│   ├── phish.py  filecheck.py  passwords.py  breach.py  incident.py
│   ├── evm.py (Keccak-256, EIP-55, approvals)  cryptobox.py (age)  exif.py
│   └── report.py  net.py   # формат звіту, HTTP-клієнт і кеш
├── services/               # Claude (anthropic SDK), CRM, налаштування й keyring
└── ui/console.py           # рендер звітів, статус, підказки
```

Claude: офіційний `anthropic` SDK зі стрімінгом, модель `claude-opus-5-5` (змінюється через `/model`),
серверний fallback на випадок відмови моделі.

## Тести

```bash
pytest
```

Понад 120 тестів; мережа скрізь підмінена (OSV, NVD, CISA, HIBP, Pwned Passwords, Etherscan, MalwareBazaar),
тестові SSH-ключі, журнали, git-репозиторії, JPEG/PNG з GPS генеруються на льоту. Сумісність шифрування
перевіряється справжньою утилітою `age`, якщо вона встановлена.
